# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in den, please report it
responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please email security concerns to the maintainer. You can
find contact information on the GitHub profile of
[@marcelocantos](https://github.com/marcelocantos).

## What to Report

- Path traversal in package extraction
- Command injection
- Privilege escalation
- Download integrity bypass
- Credential leakage
- Any issue that could compromise a user's system

## Response

- Acknowledgement within 48 hours
- Fix timeline communicated within 1 week
- Credit given in the release notes (unless you prefer anonymity)

## Scope

- The `den` CLI tool
- The `install.sh` installer script
- The daemon process
